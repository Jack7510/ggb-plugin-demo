# 教学插件需求与验收

## 状态与依据

本文件定义首轮教学目标、范围、非目标和可观察的验收条件。当前已实现独立 v2 CLI
的 doctor/check/build/preview、声明要求范围内的正式交付，以及每个交互样本独立
重载后的真实鼠标拖动门禁；固定实验保留作回归。可分发 Skill 已编写并通过静态检查，
本阶段用户追加授权 Codex 本地打包与安装，已取得本机注册、原生 Skill 发现与安装副本 CLI 证据；完整门禁状态见验收记录。DSH 和发布仍未验收。

需求依据为本阶段用户要求及[录制脚本](recording-script.md)的首轮范围。
[能力迭代脚本](capability-iteration-script.md)描述后续计划，不自动扩大本轮承诺。
“必须”表示交付门禁；“可以”表示可选行为。

架构、流程、状态和组件责任见 [arch.md](arch.md)；请求、CLI、报告、错误码和
preview 契约见 [demo-contract.md](demo-contract.md)；实际运行证据见
[acceptance.md](acceptance.md)。

## 目标用户与命名

目标用户是在 Codex 或 DSH 中通过文字要求新建二维数学构造的使用者，以及需要复现
开发、核验和安装过程的教学录制者。

| 对象 | 固定名称 |
| --- | --- |
| 插件及工程 | `ggb-plugin-demo` |
| Skill | `ggb-demo-construction` |
| 初始化 Skill | `setup`（只准备当前安装副本） |
| Codex 本地来源 | `ggb-plugin-demo-local` |

GGB 指 GeoGebra 原生构造文件。CLI 指本地命令行工具。DSH npm 包名、发布账号、
发布目标和版本尚未确认，不得借用现有包名或覆盖已有来源。

## 责任与边界

Agent 使用宿主已有的推理能力理解题意、列出必需条件，并按 Skill 编写原生请求；
Skill 只提供范围、请求编写和调用规则，不执行数学运算，也不授予通过结论；本地 CLI
检查输入、管理资源、调用真实 GeoGebra、执行逐条件核验、独立重载和交付门禁；
GeoGebra 解释原生命令的数学语义并建立对象及依赖。Agent 的文字判断不能替代引擎
证据。组件、数据流和状态模型统一见 [arch.md](arch.md)。

## 支持范围

- 只承诺新建二维构造的首个端到端教学案例：作三角形 ABC，取 AB 中点 M，连接 CM；
  将 M 和 CM 标红，显示点名；拖动 A 后检查中点关系和中线联动。
- 演示初始坐标可选 A=(0,0)、B=(6,0)、C=(2,4)，必须记录为演示选择，不写成用户
  给定条件。
- 自动构造、核验、导出和独立重载使用专用 headless 资源；适用拖动验收必须使用
  真实鼠标，不能仅以 API 改坐标代替鼠标证据；成功交付后的专用交互预览必须加载
  同一份交付 GGB。
- 报告必须逐条关联原题必需条件，区分初态、独立重载和适用交互样本；未决或无法
  判定不得记为通过。报告结构以 [demo-contract.md](demo-contract.md) 为准。
- 有限样本通过不等于所有二维题目通过，也不等于一般数学证明。

不做：已有 GGB 编辑、三维、复杂 CAS、题目答案或完整证明、按题型关键词路由、
第二套数学命令语言、额外模型服务、Worker、MCP、WorkBuddy、公共插件目录收录。
本阶段实现独立 CLI、完整交付验证与真实鼠标拖动门禁，并编写、静态验证可分发
Skill；本阶段另增加 Codex 本地包与安装，不安装 DSH，不公开发布。完整 triangle.json 保留拖动
要求；只有初态、独立重载和拖动样本全部通过才可交付。triangle-static.json 是无
拖动技术子案例，不能冒充完整案例。不支持的交互形状必须显式失败。新增数学范围
必须先修订需求，再增加验收证据。

## 逐条可观察的验收条件

以下为验收要求。A03–A10、A12 已取得本地 CLI 的案例证据。A11 仅部分验证：
已验证正常成功、执行失败与 preview 就绪后的信号退出；桥接超时只做了单元测试。
build 的完整信号取消与端到端超时清理仍未验收，不能把 A11 标为完成。A02 的原文
到清单完整性仍需录制者独立复核；A01 双宿主与独立安装仍未验收。有限样本通过
不表示全部验收完成。

| 编号 | 操作或场景 | 必须观察到的证据 |
| --- | --- | --- |
| A01 | 在 Codex 和 DSH 各自的新会话输入贯穿案例原文 | 两个宿主分别识别教学 Skill、调用本次安装副本；保留宿主、版本、请求和工具结果；缺少宿主则标未验收 |
| A02 | 对照原文与请求 | 对象、关系、颜色、标签和拖动要求逐项对应；演示坐标单独记录；由录制者复核无遗漏，不能仅凭模型生成的 checks 自评完整性 |
| A03 | 检查请求和执行记录 | 数学构造使用 GeoGebra 原生命令；真实引擎产生对象；生产执行路径没有三角形等题型关键词分支或预制答案路由 |
| A04 | 检查运行时身份并启动诊断 | 记录固定官方运行时的版本、来源、摘要和许可；真实 applet smoke 通过，不能只检查文件存在 |
| A05 | 执行贯穿案例初态核验 | 引擎事实显示 A、B、C 构成非退化三角形，M 是 AB 中点，CM 连接 C 与 M；M、CM 为红色且点名可见；截图可读 |
| A06 | 对照动态关系与错误变体 | M、CM 有原生依赖；静态坐标伪装中点等格式合法错误能被关系或交互门禁拒绝，不能只用语法错误充当反例 |
| A07 | 导出后在新的独立 applet 中读取磁盘 GGB | 不复用原 applet 内存状态；重新检查对象、关系、颜色和标签；报告记录重载结果 |
| A08 | 在重载构造上用真实鼠标拖动 A | 记录操作前后 A 的实际位置、M 的中点关系和 CM 联动事实及截图；A 未实际移动或检查未执行则不得通过 |
| A09 | 检查成功交付目录 | 交付产物齐全、同属本次运行；GGB 可重载；报告逐条显示结果；截图来自实际构造；清单能定位版本和产物 |
| A10 | 执行原生命令错误、条件不成立、缺少检查、重载失败或引擎不可用场景 | 非零退出且提供阶段、原因和诊断位置；不返回正式成功目录；不放宽容差、删除条件或以旧结果替代 |
| A11 | 执行成功、失败、超时及取消路径 | CLI 均释放本次浏览器、服务及临时资源；资源关闭失败阻止正式交付；预览资源的关闭方式另有明确说明 |
| A12 | 成功后打开专用交互预览 | 载入清单关联的同一 GGB，可拖动；预览失败单独报告，不伪造或替换交付 |

### 独立安装验收：不借用样板仓库或其他客户端缓存

这是单独的安装门禁，不以开发目录运行成功替代。安装阶段必须在新的独立安装根分别
验收 Codex 与 DSH，记录包或来源身份、实际解析路径、依赖和运行时来源。在样板仓库、
开发目录构建产物及其他客户端安装缓存不可用的条件下，从本教学包与已声明的来源
准备依赖和运行时，运行真实引擎诊断、贯穿案例及应拒绝输入。不得复制、软链接或
回退使用样板仓库或其他客户端的 `dist`、`node_modules`、`.runtime`、安装副本或
旧产物。显式声明的系统 Node 和浏览器可作为前置条件，须记录版本与路径。缺少安装
包、运行时或宿主时判为未验收；引用外部缓存才能通过时判为安装验收失败。

## 失败时不得交付

任一必需条件失败、未执行、未决或无事实证据时，CLI 必须阻止正式交付。以下情况也
必须阻止：引擎启动或命令执行失败；对象未定义或构型不满足条件；导出文件不可读；
独立重载或拖动核验失败；报告、截图或运行身份不完整；资源关闭失败；输出写入失败。
不得把部分文件、诊断截图或旧 GGB 表述为成功产物。

失败可以保留隔离的请求、日志、暂存文件和诊断截图，但必须标记失败阶段与原因，
不能出现在正式成功清单中。Agent 只能引用 CLI 的真实结果，不能自行改写通过状态。
输入不在支持范围时应明确拒绝或标注未支持，不能削减原题要求后宣称完成。错误码、
退出码和诊断位置见 [demo-contract.md](demo-contract.md)。
